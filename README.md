# Hearline

本地实时字幕与同声传译（桌面优先）。灵感来自 [Cicada / 知了](https://github.com/wquguru/cicada) 的产品形态，但是**全新项目**：壳层用 [MyGo](https://github.com/egoist/mygo)，识别 / 翻译 / 纪要全部走本机模型，不依赖 Ling、Google 等云端 API。

> 不是 Cicada 的 fork，也不是 NSGo / MyGo 本身。

## 目标

- 任意会议、直播：本机听系统声 → 实时字幕（可双语）
- 可选：按住说话做同声传译（虚拟麦回灌）
- 可选：边听边写结构化纪要
- 隐私默认：音频与推理不出机

## 技术选型（已定）

| 层 | 选择 |
|---|---|
| 桌面 UI 壳 | **MyGo**（Go + 原生窗口） |
| ASR | 默认 **SenseVoice-Small** Q8（~250MB，纯 CPU 约 20× 实时）；备选 **Qwen3-ASR-0.6B** Q8（多语更强、更重） |
| 翻译 / 纪要（LLM） | **本地优先**：默认本机小模型（如 Qwen2.5-0.5B / 1.5B Q4，llama.cpp 等）；**可选手动切到远程** OpenAI 兼容 API（用户自填 base URL + key）。ASR 仍默认本机 |
| 采集 | macOS 系统声 tap；Windows WASAPI 环回或虚拟声卡；Linux PipeWire |
| 传译输出 | 各端虚拟麦（BlackHole / VB-Cable 等，驱动不随包分发 GPL 时按官方安装） |

参考实现脉络：`miaoboai/client-pulse-vcam` 里 MyGo / NSGo 薄客户端实践（含 PR #40 移动预览），本仓库只借鉴壳与跨端节奏，不复用业务代码。


## LLM 配置（本地优先）

翻译与纪要走同一套 LLM 后端，配置原则：

1. **默认：本地** — 启动即用本机量化小模型，不要求任何云端 key；音频与推理默认不出机。
2. **可选：远程 OpenAI 兼容** — 设置里可切换后端为 `remote`，填写：
   - `base_url`（例如 `https://api.openai.com/v1` 或任意兼容网关）
   - `api_key`
   - `model`（远端模型名）
3. **切换粒度** — 至少支持全局切换；后续可拆成「翻译 / 纪要」分别选本地或远程。
4. **安全** — key 只存本机用户可读文件（权限收紧），不进日志、导出和仓库；切回本地时可不清除已保存的远程配置。
5. **失败退回** — 远程不可用时可提示并退回本地（可配置是否自动退回）。

ASR（SenseVoice / Qwen3-ASR）与 LLM 后端独立：一期默认 ASR 始终本机；远程选项只覆盖翻译与纪要所用的 LLM。

## 三期路线

### 一期 · 桌面本地听写与字幕

- MyGo 桌面壳（macOS / Windows / Linux）
- 系统声采集 → SenseVoice-Small 本机 ASR
- 默认本机小模型做句级翻译，双语字幕条；设置里可切 OpenAI 兼容远程 LLM
- 默认无云端 key；先打通「听得到、认得准、出得去字」

### 二期 · 纪要与传译

- 默认本机小模型边听边写结构化纪要（要点 / 待办 / 术语表）；可切远程 OpenAI 兼容 API
- 按住说话 → 本机 ASR + 翻译 + TTS → 虚拟麦
- 会话落盘与导出（Markdown / SRT 等）

### 三期 · 移动端遥控与看字幕

- 手机不做系统声采集主体；对齐「薄客户端」思路
- 遥控桌面会话、同步看字幕 / 纪要
- 与桌面同局域网或本机桥接，默认不上传音频

## 非目标（初期）

- 不往会议里塞机器人 Bot
- 不以云端 ASR / 云端纪要为**默认**路径（远程 LLM 仅作可选项）
- 不打包 GPL 虚拟声卡驱动进安装包（需时官方下载 + 校验）
